摄像头打不开？

正在检测…
  1. 设备是不是被系统停用了：打开「设备管理器」→「摄像头」。如果看到 Integrated Camera 显示「未连接」，说明硬件根本没上电，网页做什么都没用 —— 需要去 BIOS 或机身上的开关解决，见下一条。
  2. BIOS / 快捷键：联想等笔记本在 BIOS 里有 Camera 开关（开机按 F2 → Configuration → Camera → Enabled）；部分机型有 Fn + 摄像头图标键 或物理防窥拨片。
  3. 被其它程序占用：微信 / 钉钉 / Teams / 腾讯会议 正在使用摄像头时，浏览器会报「设备被占用」，关掉它们再试。
  4. 浏览器权限：点地址栏左侧的摄像头图标 → 允许；或在 设置 → 隐私 → 网站设置 → 摄像头 里把本站改成「允许」。
  5. 必须是 https：本地 file:// 打开时部分浏览器会直接禁用摄像头，用本地服务器或 https 访问即可。
