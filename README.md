# 足迹地球 · Travel Globe

把《这几年，我去了这些地方（完整版）.pptx》里的 11 座城市、23 段行程，做成一颗可以 360° 旋转的 3D 地球。

- **数据**：西安 · 昆山 · 武汉 · 无锡 · 大连 · 南京 · 丹阳 · 常州 · 兰州 · 成都 · 北京（2024.06 — 2026.02）
- **交互**：拖动 / 方向键 360° 旋转，滚轮或双指缩放，点击城市看每一趟的故事，底部时间线可播放
- **手势**（可选）：打开摄像头后，手掌移动旋转、拇指与食指捏合缩放；画面只在浏览器本地处理，不会上传
- **技术**：原生 HTML/CSS/JS + Three.js（本地 vendored，无需外网 CDN）

## 本地预览

```bash
python -m http.server 8787 --bind 127.0.0.1
# 打开 http://127.0.0.1:8787/
```

> 不要直接双击 `index.html`：`file://` 下浏览器会禁用 ES module 与摄像头。

## 摄像头说明

页面会先做体检（安全上下文 / mediaDevices / 是否检测到摄像头设备），失败时给出具体原因。
如果系统「设备管理器 → 摄像头」里设备显示“未连接”，那就是硬件层面没上电（BIOS 开关、Fn 快捷键或防窥拨片），网页无能为力。

## 部署

仓库根目录即站点根目录，推送到 `main` 后在 Settings → Pages 选择 `main / (root)` 即可。
附带 `.nojekyll` 跳过 Jekyll 构建。
